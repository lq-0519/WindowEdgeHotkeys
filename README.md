# WindowEdgeHotkeys

一个 macOS 菜单栏窗口布局工具。把鼠标移到目标显示器，按一次快捷键，就能把前台窗口移过去并调整布局，减少多显示器之间拖动、缩放窗口的操作。

还可以在指定显示器的一侧留出空间，用于放置聊天软件、笔记或其他常驻窗口；并根据笔记本开合盖和外接显示器状态自动调整 Dock。

## 窗口布局

- 默认全局快捷键为 `⌃⌥⌘↩`，可以在设置中重新录制。
- 前台窗口移动到鼠标所在的显示器。
- 指定显示器可选择左、上、右、下任一方向留白，比例为 0～90%，支持小数，默认左侧 10%。
- 其他显示器铺满可用区域；0% 留白也表示铺满。
- 排除名单中的应用保留窗口尺寸，跨屏时只居中移动。
- “始终全屏”的应用铺满可用区域，排除名单优先。
- 支持登录后自动启动，设置自动保存。

这里的铺满使用显示器可用区域，不进入 macOS 原生全屏，也会避开菜单栏和 Dock。应用自身的最小尺寸或窗口限制可能影响实际布局。

## 使用示例

笔记本连接两台显示器时，可以把一台设为主要工作屏并在左侧留出 15%，另一台保持铺满。鼠标放到想使用的显示器，按快捷键，当前编辑器或浏览器窗口就会采用该屏的布局。

对不希望缩放的应用加入排除名单，只移动窗口；需要尽量利用屏幕空间的应用加入始终全屏名单。

## Dock 自动调整

设置中提供两个独立开关：

| 策略 | 行为 |
| --- | --- |
| 根据笔记本开合盖调整位置 | 开盖时放底部；合盖且有外接显示器时放左侧；没有外接显示器时放底部 |
| 根据外接显示器自动隐藏 | 没有外接显示器时开启自动隐藏，有外接显示器时关闭自动隐藏 |

位置策略默认开启，自动隐藏策略默认关闭。开启自动隐藏策略后，当最后一台外接显示器断开、Dock 成功切到隐藏时，会将当前 Space 中符合条件的可见窗口铺满内建屏。

自动铺满会跳过排除名单、隐藏应用、最小化窗口、原生全屏窗口及不可调整大小的窗口。Dock 位置和自动隐藏属于系统全局偏好；关闭策略后保留当时的系统设置。

## 环境与构建

- macOS 13 或更新版本，当前脚本以 macOS 13 为编译目标。
- Xcode Command Line Tools；使用 Swift 和系统框架，无第三方包依赖。
- 窗口调整需要辅助功能权限；Dock 自动调整可能需要允许控制“系统事件”。

在项目目录执行：

```bash
./build_local_signed.sh
```

构建结果为 `dist/WindowEdgeHotkeys.app`。退出旧版后，将其安装或替换到 `/Applications/WindowEdgeHotkeys.app`，再从固定路径启动。

当前脚本依赖作者本机已有的 `InputHoldSwitcher Local Code Signing` 证书，缺少证书时停止，不生成新证书或退回临时签名。其他 Mac 需要先适配 [构建脚本](build_local_signed.sh) 中的稳定签名身份。

## 首次设置与权限

1. 启动应用，打开菜单栏“设置”。
2. 在“系统设置 → 隐私与安全性 → 辅助功能”中授权窗口调整。
3. 选择指定显示器、留白方向和比例，按需配置应用名单。
4. 把鼠标放到目标屏幕，按 `⌃⌥⌘↩` 检查窗口布局。
5. 按需开启 Dock 策略和登录自启动。

Dock 策略首次需要改变系统设置时，macOS 可能询问是否允许控制“系统事件”。拒绝后可以通过设置中的“打开自动化设置”和“重试”恢复。

更新时长期保持同一证书、Bundle ID `com.local.WindowEdgeHotkeys` 和安装路径，有助于维持辅助功能权限；首次从临时签名迁移或系统权限被重置时，可能仍需重新授权。

## 常见问题

**窗口没有调整？** 检查辅助功能权限、快捷键冲突，以及目标窗口是否允许缩放。某些应用的窗口或面板不支持标准布局操作。

**窗口没有精确达到留白比例？** 应用可能有最小尺寸限制。程序会尽量把实际窗口放回可用区域，必要时减少留白。

**外接显示器判断与预期不同？** 镜像、DisplayLink、AirPlay、Sidecar 或系统报告的虚拟显示器也可能被识别为外接显示器。

**关闭 Dock 策略后位置没有恢复？** 关闭开关会停止后续自动调整，保留当前系统偏好；需要时可自行设置 Dock。
